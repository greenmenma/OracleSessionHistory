# 画面仕様

左メニューの「監視対象」で対象 DB を絞り込めます（すべて／個別）。選択はブラウザに保存されます。

## サマリー

現在の状態を表示します（5 秒ごとに自動更新）。

| 項目 | 内容 |
|---|---|
| 接続数 | 接続中のセッション数 |
| アプリ数 | 接続中セッションのアプリ（IIS プール・exe 等。[process-info.md](process-info.md)）の種類数 |
| 端末数 | 接続中セッションの実行端末（MACHINE）の種類数 |
| 履歴数 | 切断済みセッションの件数 |
| 本日のログオン | 本日ログオンしたセッション数 |
| DB Linkの可能性 | 接続中のうち ORACLE.EXE / oracle@host からの接続数 |

ほかに、監視対象ごとの状態（収集中／取得失敗 n 回／停止）、接続数の多いアプリ・端末のランキングを表示します。

Oracle 内部プロセス（`ORACLE.EXE (J000)` などのジョブ・パラレル実行・バックグラウンド）は数えません。DB Link の可能性があるもの（括弧なしの `ORACLE.EXE` / `oracle@host`）は数えます。タイルやランキングをクリックするとセッション履歴に遷移します。

## セッション履歴

- 検索しなくても表示し、**ログオン時刻が新しい順** に並べます（50 件ずつページング、10 秒ごとに自動更新）。
- Oracle 内部プロセスと、このシステム自身（Batch・Server）の接続は既定で表示しません（「Oracle 内部プロセス・このシステムの接続も表示」をチェック、または種別で選ぶと表示）。このシステムの接続は MODULE が `OracleSessionHistory`、または PROGRAM が `OracleSessionHistory.` で始まるもので判定します。
- DB Link の可能性がある `ORACLE.EXE` の行は、DB Link 接続元 DB 上で利用元を特定できた場合に「DB Link 経由: アプリ（端末）」を表示します。
- 検索条件：キーワード（端末・アプリ・補足・実行ファイル・コマンドライン・プログラム・ユーザ・スキーマ・モジュール・アクション・CLIENT_INFO・ジョブ名・SQL）、状態（接続中／切断済み）、種別、実行端末、アプリ、接続ユーザ、実行ユーザ（OSUSER・プロセスの実行ユーザ）、期間（その期間に接続していたセッション）
- 「端末・アプリを完全一致」：接続アプリ・サマリーのランキングから開くとチェックされます。DB Link 経由で接続元を特定した `ORACLE.EXE` の行は、接続元の端末・アプリで一致させます。端末名は前後の空白を除いて保存します。チェックしたまま端末・アプリの欄を書き換えると、部分一致に戻ります。
- 列：状態、監視対象、ログオン、切断（推定の場合は「推定」）、接続時間、実行端末、**アプリ**（アプリ名と補足の 2 行。プロセス情報が未取得・失敗の場合はバッジ）、実行ユーザ、接続ユーザ（スキーマが異なれば併記）、モジュール、種別
- 行をクリックすると詳細パネルを表示：接続アプリ（プロセス情報・取得状態）、利用システムの特定情報（Oracle）、ジョブ・親セッション、DB Link の接続元、SQL

## 接続アプリ

木の形で、ログオン回数を期間別に表示します（折りたたみはありません）。Oracle 内部プロセスは含みません。

```
端末A
  app1.exe
  w3wp.exe
    Pool1                 … IIS のアプリケーションプール（補足にサイト／パス）
    (プール不明)          … プールを特定できていないもの
  sqlplus.exe
    月次集計.bat          … 実行元（バッチ・スクリプト、手で実行した cmd.exe、起動したプログラム）
  ORACLE.EXE              … 端末A が DB サーバーで、DB Link 経由で使われている場合
    DB Link 基幹DB        … 接続元を特定した DB Link 接続元（設定で登録した名前）
      app3.exe            … 接続元のアプリ（補足に「接続元: 接続元の端末」）
      w3wp.exe
        Pool3
      sqlplus.exe
        日次.cmd
    (接続元不明)          … 接続元を特定できていない ORACLE.EXE
端末B
  …
```

- 実行ファイルの段は、アプリ名から決めます（`IIS: プール` は w3wp.exe、`sqlplus.exe: 実行元` は sqlplus.exe、それ以外は PROGRAM。`AppIdentifier.SplitForTree`）。下の段が無い実行ファイルは 1 行です。
- DB Link 経由のセッションは、接続元の端末ではなく DB サーバーの端末（`ORACLE.EXE` の MACHINE）の下に置きます。接続元の端末は、接続元のアプリの行の補足に出します。
- 各段は「本日〜1ヶ月」の多い順です（「(不明)」の行は最後）。端末の行は下の段の合計です（監査証跡で補った列を除く）。
- 行をクリックすると、その行のセッション履歴を開きます（端末は MACHINE の完全一致、DB Link 接続元・経由・実行ファイル・アプリの条件付き。一覧の上部にバッジで表示し、✕ で外せます）。

### 監査証跡での補完

このシステムの履歴が 2 ヶ月分たまるまでは、履歴が無い期間を監視対象 DB の `DBA_AUDIT_SESSION`（成功したログオン）の件数で補います。

- Batch が 1 時間ごと（`Collector:AuditLogonMinutes`）に、「2 ヶ月前の同日」から「最初に観測した日」までの日・端末（USERHOST）ごとの件数を取得し、`AuditLogonCounts` に保存します（このシステム自身の接続は除く）。最初に観測した日は途中からの履歴のため、監査の件数を使います。履歴が 2 ヶ月分たまると取得しません。
- 監査証跡には PROGRAM が無いため、件数は **端末の行だけ** に加えます（アプリの行は履歴の件数のみ）。履歴に無い端末も、監査の件数だけの端末の行として表示します。
- 監査の件数を使った列には「※」を付け、画面上部に補完した期間と取得日時（失敗した場合は理由）を表示します。
- 絞り込み時は、端末名が一致する場合だけ監査の件数を加えます（アプリ名での絞り込みでは加えません）。
- 権限は [oracle-privileges.md](oracle-privileges.md)。

| 列 | 期間 |
|---|---|
| 本日 | 本日 0:00 以降 |
| 1日前〜6日前 | 各日の 0:00〜24:00 |
| 本日〜1ヶ月 | 1 ヶ月前の同日 0:00 以降（本日を含む） |
| 1ヶ月〜2ヶ月 | 2 ヶ月前の同日 0:00 〜 1 ヶ月前の同日 0:00 |

- 回数は Oracle の `logon_time` で集計します。
- 日別の列は回数に応じて背景色を付けます。行をクリックするとその端末・アプリのセッション履歴を表示します。
- 「本日〜1ヶ月」の多い順に並べます。

## DB Link 利用元

DB Link 接続元 DB で、DB Link を使っていたセッションの一覧です。特定方法（プロセス一致／SQL／シノニム）と、プロセス一致した場合は監視対象側のセッションへのリンクを表示します。「実行アプリ」は接続元端末のプロセス情報で特定したアプリ（取れるまでは PROGRAM）と、コマンドラインです（[process-info.md](process-info.md)）。

## 設定

- 監視対象の追加・編集・削除、接続テスト
- 監視対象ごとの「DB Link 接続元」：接続元 DB の接続文字列を入力 →「DB Link 一覧を取得」→ 監視する DB Link を選択 → 保存
- 接続文字列のパスワードは `********` で表示され、変更しなければ保存済みの値が使われます。
- 「プロセス情報の取得」：有効／無効、アカウント・パスワード、DNS サフィックス、タイムアウト、対象外の端末、接続テスト（[process-info.md](process-info.md)）
