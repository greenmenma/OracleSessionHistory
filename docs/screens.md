# 画面仕様

画面上部の「監視対象」で対象 DB を絞り込めます（すべて／個別）。選択はブラウザに保存されます。

## サマリー

現在の状態を表示します（5 秒ごとに自動更新）。

| 項目 | 内容 |
|---|---|
| 接続数 | 接続中のセッション数 |
| アプリ数 | 接続中セッションの実行プログラム（PROGRAM）の種類数 |
| 端末数 | 接続中セッションの実行端末（MACHINE）の種類数 |
| 履歴数 | 切断済みセッションの件数 |
| 本日のログオン | 本日ログオンしたセッション数 |
| DB Linkの可能性 | 接続中のうち ORACLE.EXE / oracle@host からの接続数 |
| 実行中ジョブ | 接続中のうちジョブ情報が紐付いたセッション数 |

ほかに、監視対象ごとの状態（収集中／取得失敗 n 回／停止）、接続数の多いプログラム・端末のランキングを表示します。タイルやランキングをクリックするとセッション履歴に遷移します。

## セッション履歴

- 検索しなくても表示し、**ログオン時刻が新しい順** に並べます（50 件ずつページング、10 秒ごとに自動更新）。
- 検索条件：キーワード（端末・プログラム・ユーザ・スキーマ・モジュール・アクション・CLIENT_INFO・ジョブ名・SQL）、状態（接続中／切断済み）、種別、実行端末、実行プログラム、接続ユーザ、OS ユーザ、期間（その期間に接続していたセッション）
- 列：状態、監視対象、ログオン、切断（推定の場合は「推定」）、接続時間、実行端末、実行プログラム、接続ユーザ、実行スキーマ、OS ユーザ、モジュール、種別、SID
- 行をクリックすると詳細パネルを表示：利用システムの特定情報、ジョブ・親セッション、DB Link の接続元、SQL

## 接続数表

実行端末 × 実行プログラムごとに、ログオン回数を期間別に表示します。

| 列 | 期間 |
|---|---|
| 本日 | 本日 0:00 以降 |
| 1日前〜6日前 | 各日の 0:00〜24:00 |
| 本日〜1ヶ月 | 1 ヶ月前の同日 0:00 以降（本日を含む） |
| 1ヶ月〜2ヶ月 | 2 ヶ月前の同日 0:00 〜 1 ヶ月前の同日 0:00 |

- 回数は Oracle の `logon_time` で集計します。
- 日別の列は回数に応じて背景色を付けます。行をクリックするとその端末・プログラムのセッション履歴を表示します。
- 「本日〜1ヶ月」の多い順に並べます。

## DB Link 利用元

DB Link 接続元 DB で、DB Link を使っていたセッションの一覧です。特定方法（プロセス一致／SQL／シノニム）と、プロセス一致した場合は監視対象側のセッションへのリンクを表示します。

## 設定

- 監視対象の追加・編集・削除、接続テスト
- 監視対象ごとの「DB Link 接続元」：接続元 DB の接続文字列を入力 →「DB Link 一覧を取得」→ 監視する DB Link を選択 → 保存
- 接続文字列のパスワードは `********` で表示され、変更しなければ保存済みの値が使われます。
